# 🛡️ Cybersecurity Awareness Bot

## 📌 Overview
The **Cybersecurity Awareness Bot** is a console-based application developed in **C#**. It is designed to educate users about essential cybersecurity concepts through an interactive chatbot and menu system.

The application provides users with basic knowledge about:
- Password Safety  
- Phishing  
- Safe Browsing  

---

## 🎯 Features
- 🔊 Plays a welcome sound at startup  
- 🤖 Displays an ASCII chatbot interface  
- 👤 Prompts user for their name  
- 💬 Interactive chatbot conversation  
- 📋 Menu-driven system  
- 🎨 Colored console output  
- 🚪 Exit option to close the program  

---

## 🧱 Project Structure

### 🔹 Chatbot Class
Handles all user interactions:
- Displays greetings and messages  
- Plays welcome audio  
- Accepts user input  
- Shows ASCII art  

### 🔹 Menu Class
Manages:
- Displaying menu options  
- Accepting user choices  
- Showing cybersecurity awareness information  

### 🔹 Program Class
- Entry point of the application  
- Controls program flow  
- Runs the chatbot and menu loop  

---

## 📋 Menu Options
1. Password Safety  
2. Phishing  
3. Safe Browsing  
4. Exit  

---

## ▶️ How It Works
1. The program starts and plays a welcome sound.  
2. The chatbot greets the user.  
3. The user enters their name.  
4. A welcome message is displayed.  
5. The main menu appears.  
6. The user selects an option.  
7. Information is displayed based on the selection.  
8. The program exits when the user selects **Exit**.
